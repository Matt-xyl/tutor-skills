# Code of conduct

Discuss the work and its evidence with respect for the people involved. Criticism of an instruction, mathematical claim, or piece of code is welcome. Personal insults, harassment, discrimination, threats, and publishing someone else's private information are not.

Use small anonymized examples when reporting tutoring problems. Do not post private conversations, study records, credentials, or unpublished work without permission. Be clear about what an example establishes and accept corrections to your own claims.

Matt-xyl maintains this repository and may edit or remove contributions that violate these expectations, restrict participation, or report abuse to GitHub. Avoid reposting harmful content to explain a report. Use GitHub's reporting tools for harassment or exposure of private information; they allow a report without creating another public issue containing that information.

These expectations apply to issues, pull requests, and other project discussions on this repository.
